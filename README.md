# Калькулятор «Вектор»

Калькулятор, который ставится на телефон как приложение и работает без интернета.

Обычный и инженерный режим, дроби с решением по шагам, уравнения (линейные, квадратные, кубические, системы и уравнения любого вида), проценты и кредит, перевод единиц, даты, статистика, режим программиста.

## Как установить
Откройте сайт приложения в браузере телефона:
- **Android (Chrome):** меню «⋮» → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».

После первого открытия калькулятор работает и без интернета.
